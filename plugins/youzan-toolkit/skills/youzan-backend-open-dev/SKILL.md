# 有赞云后端开放开发

## 原则

先读取当前项目实现，再使用 `yzy-knowledge-search` 确认接口、鉴权、权限和扩展点契约。不要用通用开放平台经验替代有赞云官方规则。

## 工作流程

1. 判断需求属于开放 API、消息推送、后端扩展点、授权、能力包或接口权限。
2. 查询官方知识，确认接口或消息标识、参数、版本、适用应用类型和权限要求。
3. 必要时使用 `youzan-open-platform` 核对当前应用已拥有的能力；控制台现状不能替代规则说明。
4. 检查现有项目的封装、错误处理、幂等、重试和日志方式。
5. 在契约明确后做最小实现，并区分本地验证、测试环境验证和上线验证。

## 重点检查

- API：能力包、接口权限、access_token、调用环境、错误码和限流。
- 消息：订阅和授权关系、版本、异步时序、幂等与重放。
- 扩展点：触发时机、标准流程影响、超时、异常处理与回滚。
- 交易、支付、订单、会员资产和隐私数据：只使用官方文档确认过的字段与流程。

## 回答规则

- 不编造 API、参数、鉴权方式、消息或扩展点。
- 检索证据不足时明确说明缺失项。
- 涉及写入、发布、授权或线上数据变化时，执行前再次确认目标应用和环境。
